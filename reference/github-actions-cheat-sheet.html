GitHub Actions cheat sheet

Workflow vocabulary

name
The label displayed in the Actions tab.
on
The event or events that start the workflow.
permissions
The access granted to the workflow's GitHub token.
jobs
Independent units of work that may run in parallel.
runs-on
The runner environment used by a job.
steps
Ordered commands and reusable actions within a job.
uses
Invokes a reusable action at a named version.
run
Runs a shell command on the runner.
${{ expression }}
Evaluates GitHub Actions contexts, inputs, operators, or functions.

Leaven's three workflows

hello.yml              manual learning workflow
ci.yml                 PR, main push, or manual validation
dependency-review.yml  PR dependency security review

Fast diagnosis

  1. Open the failed check.
  2. Find the first failed step.
  3. Read the first concrete error in that step.
  4. Reproduce the same command locally.
