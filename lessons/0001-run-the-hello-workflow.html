Leaven GitHub Actions · Lesson 1

Run one workflow by hand

Tangible win: trigger a workflow with your own input and find the output in its step logs.

The mental model

on chooses the event. jobs groups work. runs-on chooses GitHub's temporary machine. steps run in order on that machine.

Try it

  1. Commit .github/workflows/hello.yml to main.
  2. Open GitHub → Actions → Hello Workflow.
  3. Choose Run workflow, enter a name, and run it.
  4. Open the completed run and expand both steps.

The button appears only after a workflow_dispatch workflow exists on the default branch, as documented in GitHub's manual-run guide.

Retrieval check: Before reopening the YAML, say which key controls the trigger and which key selects the runner.
Check the answer

on controls the trigger; runs-on selects the runner.
