Leaven GitHub Actions · Lesson 3

Review what a package change introduces

Tangible win: find a dependency-review summary on a pull request that changes package.json or package-lock.json.

What is different here?

The workflow delegates its core work to actions/dependency-review-action@v5. The action compares dependency snapshots across the pull request and reports newly introduced vulnerabilities or invalid licenses. It needs only contents: read in this setup.

Leaven is public, so it meets the action's availability requirement. Private repositories need GitHub Advanced Security. See the official Dependency Review Action guide.

Try it

  1. Open a pull request that changes an npm dependency.
  2. Open the Dependency Review job.
  3. Read both the step log and the job summary.
  4. Decide whether the result is informational or should block merging.
