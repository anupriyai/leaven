Leaven GitHub Actions · Lesson 2

Turn a pull request into evidence

Tangible win: identify whether a pull request fails during installation, type-checking, or the Vite build.

What the runner does

checkout → set up Node 22 → npm ci → typecheck → build

uses invokes a reusable action. run executes a shell command. The official setup-node action installs the chosen Node version and can cache npm's download cache.

Try it

  1. Push a branch and open a pull request into main.
  2. Open the Type Check and Build check.
  3. Map each visible step back to .github/workflows/ci.yml.
  4. Later, intentionally introduce a TypeScript error and observe which step turns red.
Retrieval check: Why use npm ci instead of npm install here?
Check the answer

CI should install exactly from the committed lockfile and fail if the manifest and lockfile disagree.

Ask Codex to help interpret a failed run; the first useful evidence is the earliest failed step.
